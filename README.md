# Banana Run

A retro-styled first-person shooter where you play a monkey and blast banana bandits with a banana blaster.

## Run it in a Chromebook browser

1. Open the project folder in a terminal.
2. Start a tiny server:

```bash
python3 -m http.server 8000
```

3. In Chrome, visit:

```text
http://localhost:8000
```

## Controls

- W / A / S / D: move
- Left click / Space: fire banana ammo
- Mouse: look around after locking the cursor
- R: restart the run

## Story

The jungle is under attack by banana bandits, and only a fearless monkey with a banana blaster can stop them.

## Notes

- Built with plain HTML, CSS, and JavaScript.
- No build tools or installation are needed.
- It is lightweight enough for an older Chromebook browser.
